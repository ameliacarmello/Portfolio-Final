My Thoughts 📝

Week 1 — Getting Started

January 2026

This week I learned how to access Visual Studio Code on my computer and installed the Amazon Ai Assistant. I also learned more about my classmates this week and how they are involved in GIS!

Week 2 — A Basic Interactive Map: JS Libraries and Documentation

February 2026

This week I was introduced to the basics of web mapping and interactive geographic data visualization using JavaScript libraries such as Leaflet. I learned how web maps are structured and how layers, markers, and interactive elements are built using code. I also gained experience using Visual Studio Code to create and preview web projects, which helped me understand how developers test and refine code before publishing it. In addition, I became more familiar with basic JavaScript conventions and how scripts interact with HTML elements. A major part of this week was creating a GitHub account and hosting my first interactive map using GitHub Pages. This introduced me to version control and web hosting, and showed how projects can be shared publicly online. I also used an AI assistant (Amazon Q) to support coding and troubleshooting, which helped me understand how AI tools can assist in programming while still requiring critical thinking and adjustments. Overall, this week helped me build foundational skills in web mapping, JavaScript libraries, and GitHub, while also improving my understanding of how interactive maps are created and published.

Week 3 — Customize the Location and Appearance of Your Interactive Map

February 2026

This week I expanded my skills in web mapping by working with more detailed geographic data and customizing interactive maps using JavaScript and Leaflet. I learned how to structure map data using object notation and how to properly format and display real-world information such as city names and populations. A major focus was improving map interactivity by using tooltips instead of popups and formatting text using HTML styling (bold labels and italicized values). I also practiced customizing map visuals by using different circle styles, colors, and outlines to better represent different locations. In addition, I gained experience selecting and applying different basemaps, which helped me understand how background map styles affect readability and design. I also strengthened my ability to write more specific prompts for AI tools like Amazon Q to generate and refine code more effectively. Overall, this week helped me build stronger technical skills in Leaflet, improve my understanding of how to present structured geographic data, and become more confident in customizing interactive web maps using real-world datasets.

Week 4 — Mapping with GeoJSON Data

February 2026

This week I learned how to access and integrate GeoJSON data into a web mapping environment using Leaflet. I gained experience working with the structure of GeoJSON files and linking external datasets to display real geographic information on interactive maps. I also practiced customizing map data by styling features, such as using green circle markers and applying filters to display only specific locations. This helped me understand how data can be dynamically controlled and visualized based on user-defined conditions. In addition, I became more familiar with tools like Mapbox, Geojson.io, and Mapshaper for working with and transforming spatial data. Overall, this week strengthened my ability to work with real-world geographic datasets and build interactive, data-driven web maps.

Week 5 — Put it All Together: Create a Proportional Symbol Map

February 2026

This week I learned how to build a finished interactive web map using proportional symbols, multiple layers, and user interactivity. I gained experience creating a function to scale circle markers based on real data values, which helped visually represent differences in power generation across energy sources. I also learned how to organize and manage multiple GeoJSON layers to compare different categories of data, such as biomass, geothermal, and solar energy. This included applying filters, customizing colors for each layer, and using layer controls to allow users to toggle data on and off. In addition, I developed skills in adding map interactivity through popups and clickable features, which display key information like plant names and energy capacity. I also created a legend to improve map readability and user understanding. Overall, this week strengthened my ability to design functional, multi-layered interactive maps that visually communicate complex data in a clear and user-friendly way.

Week 6 — Visual Hierarchy: Map Design for Interactive Maps

March 2026

This week I learned how visual hierarchy and design principles improve the effectiveness of web maps. I explored how layout, color, and structure influence how users interpret spatial data and how better design can improve clarity and communication. I also applied one of these principles to my existing power plant map by making design adjustments that improved user experience and made the data easier to understand. Additionally, I practiced explaining these design choices directly within the map. Overall, this week helped me move beyond just building maps to intentionally designing them to communicate information more clearly and effectively.

Week 7 — Getting Started with ARC JS

March 2026

This week I transitioned into the ArcGIS JavaScript environment and learned how to create a map using the ESRI Location Platform and a personal API key. I gained experience working with a new mapping framework and using documentation to guide development. I also learned how to load external GeoJSON data and display it as interactive map features with popups containing structured information such as names, locations, and contact details. This strengthened my ability to work with real-world datasets in a more advanced web mapping environment. Overall, this week improved my confidence using APIs, navigating technical documentation, and building interactive maps outside of Leaflet.

Week 8 — ARC JS: Data-driven Continuous Color/Choropleth Map

March 2026

This week I learned how to build choropleth maps using the ArcGIS JavaScript SDK by working with REST services and SDK visualization methods. I gained experience selecting appropriate polygon datasets and applying visual hierarchy principles to represent quantitative data clearly through color and classification systems. I also learned how to use ArcGIS SDK components such as SimpleFillSymbol and visual variables (including color stops) to customize map appearance and improve data interpretation. In addition, I practiced integrating popups to communicate key information about geographic regions and their values. Overall, this week strengthened my ability to design data-driven choropleth maps and use ArcGIS tools to visually communicate spatial patterns in a clear and effective way.

Week 9 — ARC JS: Data-driven Continuous Size/Proportional Symbol Map

March 2026

This week I learned how to build proportional symbol maps in the ArcGIS JavaScript SDK using REST service data and visual variables based on size. I gained experience working with point datasets and representing quantitative values through scaled symbols to better communicate differences in data values. I also practiced using ArcGIS SDK tools such as SimpleMarker and visualVariable properties to control symbol appearance and size. In addition, I strengthened my understanding of visual hierarchy by designing maps that clearly communicate patterns in global data. Overall, this week improved my ability to create interactive proportional symbol maps and apply ArcGIS visualization methods to effectively represent spatial data.

Week 11— Google Charts

April 2026

This week I learned how to build interactive charts using the Google Charts API and apply my programming skills in a new JavaScript-based visualization environment. I gained experience interpreting documentation to create and customize different types of charts using my own datasets. A key focus was learning how to structure data properly for chart creation and how to use Google Charts methods to generate interactive visualizations. I also practiced adapting concepts from ArcGIS and Leaflet into a different library, strengthening my ability to transfer programming knowledge across tools. Overall, this week improved my confidence in building interactive data visualizations and using JavaScript documentation to create meaningful charts from custom data.
